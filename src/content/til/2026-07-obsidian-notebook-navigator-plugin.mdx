File browser and calendar inspired by Apple Notes, Bear, Evernote and Day One

![Obsidian application displaying Notebook Navigator pane on the left with a list of folders, a list of documents in the middle  and on the right pane a note about Notebook Navigator 2.1](https://raw.githubusercontent.com/johansan/notebook-navigator/refs/heads/main/images/notebook-navigator.png)

Since last Sunday I've been checking [Obsidian's Community Plugin Notebook Navigator](https://community.obsidian.md/plugins/notebook-navigator); I had it on my `Inbox` in `Todoist` for quite some time now and finally sat around checking it.

The author describes it as a better file browser and mentions that it is inspired by various macOS and iOS application, that objectively have amazing UI and UX as their pillars.

The plugin by itself is quite "simple" in what it does, but the reality is that it is quite powerful. It has a built in calendar for daily notes (something I try to do as my journaling habit, which comes and goes like the wind).

The tool has custom grouping, custom sorting, heavy usage of properties in documents among many things. The thing that stood the most to me was that the plugin itself advertises a [1 hour `YouTube` video](https://www.youtube.com/watch?v=m2maDNtho7Y) on how to master the plugin, because, the author claims that you are probably using only a small percentage of its power; and truth be told, after only a few chapters into the video I realised all the cool things I could accomplish with it.
