File explorer tool for the terminal.

![A console terminal showing the application superfile, showcasing many different folders and a Go file preview on the far right side of the screen](https://superfile.dev/_astro/demo.CvzVaHej_Z1YPGWj.webp)

Today as I was going through [Console.dev](https://console.dev/)'s RSS feed I came accross [superfile][superfile].

The tag being a wee bit cheeky, a file explorer for those that live on the terminal. While I do a lot of work on my terminal, I don't LIVE in it, and let's be honest, GUI file explorers are quite handy, but at the same time having an easy way to explore and navigate the file structure of a project in the terminal without having to do lots of `la` (mapped on my `fish` terminal to `eza -abghHliS --git --icons=always`) and `cd` will definitely come in handy.

I have come accross another CLI file explorer in the past, and although I tried using it, it never stuck because of different reasons, lack of compatibility with certain things and terminals, etc; but `superfile` looks promising with lots of customisations, mapping your own hotkeys, etc. We'll see how long it stucks but at the very least is a nice tool to play around with.

[superfile]:https://superfile.dev
